# data/

This top-level `data/` folder is for small, project-tracked sample/reference data only
(e.g. a tiny CSV used in documentation examples or tests).

Full datasets (IMDb, SST-2, domain reviews) are downloaded into `ml/data/` by scripts
created in Phase 1, and are excluded from git via `.gitignore` due to size.

Dataset licenses and citations are tracked in `docs/resources.md`.
